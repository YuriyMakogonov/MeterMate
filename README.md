# MeterMate

Показания счётчиков электроэнергии по фото — без облака и без ИИ-сервисов.
Веб-приложение (PWA): ставится на Android, iPhone и Windows, работает офлайн,
данные хранятся только на устройстве.

## Что умеет

- **Снять показание**: живая камера с рамкой-прицелом (фонарик и зум на Android)
  или фото из галереи с подгонкой рамки и наклона.
- **Распознавание без нейросетей**: рамка делится на ячейки-барабаны, каждая
  сравнивается с эталонами цифр. Подтверждённые цифры запоминаются для каждого
  счётчика, поэтому после 1–2 показаний распознавание становится заметно точнее.
- **Несколько счётчиков** с настройкой числа барабанов и знаков после запятой.
- **Тарифы с датой начала**: если тариф сменился посреди периода, расход делится по дням.
- **Статистика**: расход и сумма по месяцам и годам, средние значения, график.
- **Excel**: выгрузка `.xlsx` с листами «Показания», «По месяцам», «По годам», «Тарифы».
- **Перенос между устройствами**: резервная копия `.json` → загрузить на другом
  устройстве. Данные объединяются без дублей, удаления тоже переносятся.

## Структура

```
app/                 ← всё, что публикуется
  index.html, manifest.webmanifest, sw.js (офлайн-кэш)
  css/app.css
  js/app.js          экраны и навигация
  js/store.js        данные (localStorage), слияние резервных копий
  js/camera.js       камера с рамкой
  js/cropper.js      подгонка рамки на снимке
  js/recognizer.js   распознавание цифр (сравнение с эталонами)
  js/stats.js        расход, стоимость, сводки
  js/xlsx.js         генератор .xlsx без зависимостей
  js/export.js       содержимое выгрузки и резервной копии
.github/workflows/pages.yml   автодеплой на GitHub Pages
```

Сборки нет: обычные HTML/CSS/JS-модули без зависимостей.

## Запуск локально

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

`--bind 127.0.0.1` оставляет сервер доступным только с этого компьютера,
поэтому macOS не спрашивает доступ к локальной сети.

Открыть http://localhost:8765/app/. Камера в браузере работает только через
`localhost` или HTTPS. На localhost service worker отключён, чтобы правки было видно сразу.

## Публикация на GitHub Pages

1. Запушить в ветку `dev` репозитория `MeterMate`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После пуша workflow выложит `app/` по адресу `https://<логин>.github.io/MeterMate/`.

На бесплатном тарифе GitHub Pages работает только для публичного репозитория.
Там лежит только код: показания и фото туда не попадают.

## Установка на устройства

- **Android (Chrome)**: открыть адрес → «Установить приложение».
- **iPhone (Safari)**: «Поделиться» → «На экран Домой».
- **Windows (Edge/Chrome)**: значок «Установить» в адресной строке.

Обновления подтягиваются сами: при запуске с интернетом приложение скачивает
новую версию, и она открывается со следующего запуска.

## Как снимать, чтобы распознавалось лучше

- Держать телефон ровно, чтобы барабаны были горизонтально, без бликов
  (на Android поможет фонарик).
- Рамка должна плотно охватывать только окошко с барабанами.
- Первые показания проверять внимательно: подтверждённые цифры становятся эталонами.
  Если распознавание испортилось: Настройки → «Сбросить обучение».
