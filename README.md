# MeterMate

Учёт электроэнергии в гаражах: показания по фото (без облака и без ИИ-сервисов),
оплаты с комиссией и тарифом, сверки, взносы, баланс и таблица в привычной раскладке.
Веб-приложение (PWA): ставится на Android, iPhone и Windows, работает офлайн,
данные хранятся на устройстве (и, по желанию, в вашей Google Таблице).

Подробный план и правила расчёта — [docs/PLAN.md](docs/PLAN.md).

## Что умеет

- **Снять показание**: живая камера с рамкой-прицелом (фонарик и зум на Android)
  или фото из галереи с подгонкой рамки и наклона.
- **Распознавание без нейросетей**: рамка делится на ячейки-барабаны, каждая
  сравнивается с эталонами цифр. Подтверждённые цифры запоминаются для каждого
  счётчика, поэтому после 1–2 показаний распознавание становится заметно точнее.
- **Несколько счётчиков (гаражей)** с настройкой числа барабанов и знаков после запятой.
- **Оплаты**: дата (по умолчанию сегодня), сумма, комиссия (по умолчанию 2%), тариф.
  Сразу видно, сколько дойдёт, сколько кВт оплачено и до какого показания.
  Тариф сохраняется в самой оплате: смена тарифа прошлые оплаты не пересчитывает.
- **Сверки** («сверено с бухгалтером, оплачено по N») и **взносы**.
- **Баланс**: последнее показание против «оплачено по» — долг или запас,
  и подсказка, сколько заплатить с учётом комиссии (округлено до красивой суммы).
- **Статистика**: оплаты и взносы по годам, расход и стоимость по показаниям.
- **Таблица `.xlsx`**: вкладка «Гаражи» в раскладке старой таблицы (с формулами)
  и вкладка «Данные» (плоский список записей). Скачать и загрузить обратно —
  перед загрузкой показывается, что изменится.
- **Импорт старой таблицы**: загрузка прежнего файла переносит всю историю.
- **Google Таблицы** (по желанию): автоотправка после каждого изменения и загрузка правок.
- **Резервная копия `.json`** для переноса между устройствами.

## Структура

```
app/                 ← всё, что публикуется
  index.html, manifest.webmanifest, sw.js (офлайн-кэш)
  css/app.css
  js/app.js          экраны и навигация
  js/store.js        данные (localStorage), слияние резервных копий
  js/camera.js       камера с рамкой
  js/cropper.js      подгонка рамки на снимке
  js/recognizer.js   распознавание цифр (сравнение с эталонами)
  js/stats.js        расход и стоимость по показаниям
  js/ledger.js       оплаты, сверки, баланс, итоги по годам
  js/sheets.js       вкладки «Гаражи» и «Данные», сравнение при загрузке
  js/legacy.js       импорт старой таблицы
  js/google.js       синхронизация с Google Таблицей
  js/xlsx.js         чтение и запись .xlsx без зависимостей
  js/export.js       выгрузка и резервная копия
google/Code.gs       скрипт для Google Таблицы
docs/PLAN.md         план и правила расчёта
.github/workflows/pages.yml   автодеплой на GitHub Pages
```

Сборки нет: обычные HTML/CSS/JS-модули без зависимостей.

## Запуск локально

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

`--bind 127.0.0.1` оставляет сервер доступным только с этого компьютера,
поэтому macOS не спрашивает доступ к локальной сети.

Открыть http://localhost:8765/app/. Камера в браузере работает только через
`localhost` или HTTPS. На localhost service worker отключён, чтобы правки было видно сразу.

## Публикация на GitHub Pages

1. Запушить в ветку `dev` репозитория `MeterMate`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После пуша workflow выложит `app/` по адресу `https://<логин>.github.io/MeterMate/`.

На бесплатном тарифе GitHub Pages работает только для публичного репозитория.
Там лежит только код: показания и фото туда не попадают.

## Установка на устройства

- **Android (Chrome)**: открыть адрес → «Установить приложение».
- **iPhone (Safari)**: «Поделиться» → «На экран Домой».
- **Windows (Edge/Chrome)**: значок «Установить» в адресной строке.

Обновления подтягиваются сами: при запуске с интернетом приложение скачивает
новую версию, и она открывается со следующего запуска.

## Как снимать, чтобы распознавалось лучше

- Держать телефон ровно, чтобы барабаны были горизонтально, без бликов
  (на Android поможет фонарик).
- Рамка должна плотно охватывать только окошко с барабанами.
- Первые показания проверять внимательно: подтверждённые цифры становятся эталонами.
  Если распознавание испортилось: Настройки → «Сбросить обучение».

## Таблица: вкладки и правила

- **«Гаражи»** — для чтения и печати: гаражи блоками, колонки как в старой таблице,
  формулы `E=C−C×D/100`, `G=E/F`, `H=I` предыдущей строки, `I=H+G`, итоги по годам и общий.
  Правки в этой вкладке **не загружаются** — при загрузке приложение покажет их предупреждением.
- **«Данные»** — одна строка на запись: `id | Гараж | Тип | Дата | Сумма | Комиссия % | Тариф | Значение | Комментарий`.
  Тип: `оплата`, `сверка`, `взнос`, `показание`, `тариф`. Можно править и добавлять строки
  (для новой строки `id` оставить пустым). Удалённая строка при загрузке предлагается к удалению.
- Скрытая вкладка `_Гаражи_снимок` — служебная, по ней находятся ручные правки в «Гаражах».

## Google Таблицы

Подключается один раз, минут за 5.

1. Создать Google Таблицу (или открыть нужную) → **Расширения → Apps Script**.
2. Удалить всё в `Code.gs` и вставить содержимое файла [google/Code.gs](google/Code.gs). Сохранить.
3. В приложении: **Настройки → Google Таблицы → «Создать надёжный ключ»** — ключ
   скопируется в буфер обмена.
4. В Apps Script: **Настройки проекта** (шестерёнка) → **Свойства скрипта** → добавить свойство
   `TOKEN` и вставить этот ключ.
5. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   «Выполнять как» — **Я**, «У кого есть доступ» — **Все**. Нажать «Развернуть»,
   разрешить доступ к таблице и скопировать адрес вида `https://script.google.com/macros/s/…/exec`.
6. В приложении вставить этот адрес в поле «Адрес скрипта» и нажать «Отправить».

«Доступ — Все» нужен, чтобы приложение могло достучаться до скрипта без входа в Google;
без ключа скрипт ничего не отдаёт и не пишет. Скрипт помечен `@OnlyCurrentDoc` —
Google выдаёт ему доступ только к этой таблице, а не ко всему Диску.

Дальше приложение само отправляет данные после каждого изменения (без интернета — когда сеть появится).
Если вкладку «Данные» правили в Google, отправка остановится с подсказкой: нажмите «Загрузить»,
проверьте изменения в предпросмотре и примените — после этого таблица пересоберётся.

Адрес скрипта и ключ хранятся только на устройстве и в резервную копию не попадают.
Ключ передаётся только в теле запроса (не в адресе), а приложение отправляет его
только на адреса вида `https://script.google.com/macros/s/…/exec`.
При изменении кода скрипта нужно сделать **Развернуть → Управление развёртываниями → Изменить → Новая версия**.

## Безопасность

- Своего сервера нет: данные в браузере на устройстве (и, если подключено, в вашей Google Таблице).
- Без внешних библиотек и скриптов. Интерфейс строится без `innerHTML`, поэтому текст
  из таблиц и файлов не может выполниться как код.
- Политика безопасности контента (CSP в `index.html`) разрешает скрипты только с сайта
  приложения, а сетевые запросы — только к нему и к Google Apps Script.
- Текст, похожий на формулу (`=…`, `+…`, `-…`, `@…`), в Google Таблицу записывается как текст.
- Данные на устройстве не шифруются: защищайте телефон блокировкой экрана.
- Кто может пушить в репозиторий, тот может выложить новую версию на все устройства:
  включите двухфакторную аутентификацию на GitHub и защиту ветки `dev`.
