# План: оплаты, взносы и таблицы

Основано на таблице пользователя «ГАРАЖ СВЕТ Взносы» и его описании.
Главный принцип: **приложение — источник данных и расчётов**, таблицы — выход
наружу (просмотр, печать, отправка) и, при желании, место для правок с
обязательным предпросмотром.

## 1. Модель учёта

Учёт ведётся по оплатам (предоплата кВт), как в таблице пользователя.

| Запись | Поля | Что считается |
|---|---|---|
| Оплата | гараж, дата (по умолчанию сегодня), сумма, комиссия % (по умолчанию 2), тариф, комментарий | дошло = сумма × (1 − комиссия/100); кВт = дошло / тариф; «счётчик до» = «оплачен по» предыдущей записи; «оплачен по» = до + кВт |
| Сверка | гараж, дата, «оплачено по», комментарий | сбрасывает «оплачено по» на указанное значение (бухгалтер, новые данные, покупка гаража) |
| Взнос | гараж, дата, сумма, комментарий | только учёт и итоги |
| Показание | гараж, дата, значение (фото или вручную) | баланс и расход |
| Тариф | дата начала, цена, гараж или все | подставляется в новые оплаты |

- **Тариф хранится внутри каждой оплаты.** Изменение тарифа влияет только на новые оплаты, прошлые не пересчитываются.
- **Комиссия** берётся из настроек (2%), её можно поменять в конкретной оплате.
- **Валюта** по умолчанию BYN. Это только подпись, без конвертации.

## 2. Баланс и подсказка суммы

- Долг или запас = последнее показание − «оплачено по» (в кВт и в деньгах по текущему тарифу).
- Подсказка оплаты: долг × тариф / (1 − комиссия), с округлением вверх до «красивой» суммы.
- В форме оплаты сразу видно, сколько дойдёт, сколько кВт, до какого показания и какой будет баланс после оплаты.

## 3. Таблица (xlsx и Google Таблицы)

Две вкладки:

- **«Гаражи» (main)** повторяет раскладку пользователя: гаражи блоками один под другим.
  Колонки: A год · B дата · C платёж · D комиссия % · E денег дошло · F тариф · G киловат ·
  H счётчик до оплаты · I оплачен по · J кВт за год · K денег за год · M–O взносы
  (дата, сумма, примечание) · P комментарий.
  Формулы: `E=C−C×D/100`, `G=E/F`, `H=I` предыдущей строки, `I=H+G`;
  итоги по годам `SUM(G)`, `SUM(C)`; общий итог по блоку.
  Сверка — отдельная строка: H = значение сверки, I = H.
  Вкладка только для просмотра: правки в ней не загружаются.
- **«Данные»** — плоский список, одна строка = одна запись:
  id · Гараж · Тип (оплата / сверка / взнос / показание / тариф) · Дата · Сумма ·
  Комиссия % · Тариф · Значение · Комментарий.
  Именно эту вкладку читает загрузка.

## 4. Выгрузка и загрузка

- **Скачать .xlsx** на устройство (обе вкладки, с формулами).
- **Загрузить .xlsx** с устройства:
  - файл MeterMate (есть вкладка «Данные») → читается «Данные»;
  - старый файл пользователя → разбор раскладки (импорт истории, см. п. 5).
- **Google Таблицы** (опция): Apps Script в таблице пользователя.
  - Автоотправка после каждого изменения, без сети — в очередь.
  - Перед записью проверяется, не правили ли «Данные» в таблице с прошлой синхронизации.
    Если правили, сначала нужно загрузить изменения.
  - «Загрузить из Google» забирает обе вкладки.
- **Предпросмотр изменений** перед любой загрузкой: новые, изменённые (было → стало),
  удалённые в таблице, есть только в приложении. Применяется только по подтверждению.
- **Проверка main**: при выгрузке рядом кладётся скрытая вкладка `_Гаражи_снимок`.
  При загрузке «Гаражи» сравнивается со снимком, и правки, сделанные в main руками,
  показываются предупреждением. Если правили только «Данные», ложных срабатываний нет.

## 5. Импорт истории из старого файла

- Блоки «1й гараж» и «2й гараж» → два счётчика.
- Даты в двух форматах (дата Excel и текст `16,04,24`). `08,11,27` → 08.11.2024
  (год из будущего заменяется годом предыдущей записи).
- Ручные правки колонки H и строки «сверено с бухгалтером», «БУХ данные», «ПОКУПКА» → сверки.
- Пометки пользователя в J/K (числа и текст) → комментарии к записям, а не показания.
- Итоги по годам из J/K не переносятся: их считает приложение.
- Взносы из M/N/O, включая «20р» и пометку о скидке 50%.
- Повторная загрузка того же файла не создаёт дублей.
